# Verification evidence

The PNG screenshots in this folder were captured from the final English-only build using Chromium at an exact 1080×1920 viewport. They include the logo screensaver, camera flow, composed review image, print-media output, QR screen, camera error, and staff panel. `results.json` records the screen-flow evidence; `functional-results.json` records mirror orientation, retake/print/QR behavior, QR auto-reset, server-down recovery, print CSS, and deliberate logo long-press checks.

`composed-photo-fixture.jpg` is a deterministic camera-fixture capture used only to verify the final canvas composition and frame alpha coverage. It is not an application asset and is not loaded by the kiosk.
